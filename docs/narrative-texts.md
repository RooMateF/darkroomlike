# 敘事文本總表(檢視/修改用)

> **用法**:這是遊戲內所有敘事文字的總覽,按「什麼時候會看到」分組,每段都標了程式出處。
> 這份檔案本身不會直接改到遊戲——**想改哪段,直接在這裡改字(或加註記),丟給我同步進程式碼**。
> 通用寫作原則:show-don't-tell、不說破設定、伏筆藏在日常細節裡不加評註。

## 1. 開場(第一次進入遊戲,逐句點[繼續])

出處:`game/src/village/narrative.ts` → `INTRO_LINES`

1. 你在一堆微弱的火堆旁醒來,身上滿是塵土與擦傷,記憶模糊得像隔著一層霧。
2. 『你醒了。』一個溫和的聲音傳來——是個陌生的女人,她正往火裡添著柴。
3. 『別擔心,你很安全。這裡什麼都沒有,只有我們兩個,還有這堆火。』
4. 她朝你伸出手。『如果你還走得動,我們可以先搭個能遮風擋雨的地方。』

### 5b. 選擇型事件(彈窗二~三選一;「(不足)」= 庫存不夠不能選)

**流浪者乞食**(未來型:餵了之後 5~12 分鐘後開獎——36% 報恩 / 25% 引來土匪 / 39% 沒下文)
- 事件:一個瘦得脫形的流浪者在村口徘徊,乞求一點吃的。
- 分他一頓熱食(穀物 -50)→ 他狼吞虎嚥地吃完,朝村子深深鞠了一躬,消失在路的盡頭。
- 塞給他一份乾糧(乾糧 -10)→ 他把乾糧緊緊抱在懷裡,一邊回頭道謝一邊小跑著離開了。
- 趕走他 → 他沒有糾纏,拖著腳步消失在暮色裡。
- **後續:報恩** → 之前那個流浪者回來了——氣色好了不少,身後還拖著一小車物資。「那頓飯救了我一命。」
- **後續:土匪**(選擇型)→ 糟了——之前那個流浪者帶著一夥土匪回來了。他把村子的位置,換成了自己的入夥資格。
  - 拿起武器抵抗(65% 勝)→ 一場混戰。土匪沒料到村子敢拚命,丟下傷者和輜重潰逃了——那個流浪者跑得最快。
  - 拿起武器抵抗(35% 敗,糧-25%+人口-30%)→ 寡不敵眾。土匪搶走了存糧,村裡有人沒能撐過那一夜。
  - 交出存糧(糧肉乾糧 -30%)→ 土匪把糧倉搜刮了一輪,罵罵咧咧地走了。至少沒有人受傷。

**流動商人**(木材≥10)
- 事件:一名流動商人來訪,提議用木材換取石材。
- 交易(木-10→石+8)→ 交易順利完成。 / 婉拒 → 商人聳聳肩,繼續上路。

**野狼群偵查**
- 事件:偵查回報附近有野狼群出沒,是否要清剿?
- 派人清剿 → 清剿成功,順便帶回了一些戰利品。 / 加強戒備就好 → 村莊提高警戒,暫時相安無事。

**鴉群**(生肉≥20)
- 事件:大群鴉鳥盤旋在晾曬場上空,不斷俯衝啄食。
- 派人驅趕(肉-20)→ 花了些功夫把鴉群趕走,只損失了一點肉乾原料。
- 隨牠們去(**肉-50%**)→ 鴉群飽餐一頓才離開——晾曬場的肉少了一半。

**旅行工匠**
- 事件:一位旅行工匠來訪,願意用手藝換一頓飽飯。
- 款待他(穀-10→石+10木+10)→ 他幫忙修整了工具,效率提升了不少,臨走前還留下些材料。
- 婉拒 → 他點點頭,沒有多說什麼就上路了。

**受傷獵人**(有空房,且付得起其中一項)
- 事件:一名外地獵人拖著受傷的腿來求助。
- 收治他(繃帶-1,人口+1)→ 傷好之後,他決定留下來——村裡多了一位好獵手。
- 給點吃的請他離開(乾糧-1)→ 他道了謝,一瘸一拐地消失在路的盡頭。

**水井疑雲**(後期)
- 事件:有村民喝了水源的水之後開始上吐下瀉,大家對那口水井起了疑心。
- 暫停取水,徹底檢查(石-50)→ 花了些材料重砌井口,情況穩定下來了。
- 應該只是吃壞肚子(**穀-30%+人口-5**)→ 幾天後,又有人倒下了……這次沒能救回來。壞掉的存糧也只能整批倒掉。

**狼群夜襲**(後期)
- 事件:野狼群夜襲了村莊外圍,幾名值夜的村民受了傷。
- 全力救治(**肉/穀-30%、肉乾-20%**)→ 所有人都保住了性命——但傷患要吃要補,存糧下去了一大截。
- 順其自然(**肉-50%、皮-40%、人口-10**)→ 沒人守夜的第二晚,狼群回來把晾曬場洗劫一空。村莊失去了一位居民。

### 5c. 超稀有訪客(約每百個事件 1 次;交換永久被動)

**拄杖老者**(中期起,未有【潛行】)
- 事件:一位拄著杖的老者在村口駐足。他認得原野上那些東西的習性——「牠們靠聲音找人。我可以教你們怎麼移動,但你們得提供我一批過冬的東西。」
- 供養他(皮革-40、肉乾-20)→ 老者住了幾天,教會了你貼地換步的走法。(獲得【潛行】:遠征的遭遇率降低)
- 送他上路 → 老者不置可否地點點頭,拄著杖走遠了。

**裹布的高大旅人**(後期起,見過鐵,未有【機巧】)
- 事件:一個渾身裹著破布的高大旅人站在村口。布縫間露出的不是皮膚。它伸出手,聲音像敲在金屬管上:「鐵。和燒的油。」
- 給它(鐵-60、燈油-10)→ 它半天之內改造了村裡所有的工具,沒有人看清它是怎麼做的。天黑前它就走了。(獲得【機巧】:手動採集成果 +25%)
- 拒絕 → 它靜止了很久,久到大家以為它壞了——然後一言不發地轉身離開。

**褪色祭袍的人**(後期起,見過異晶,未有【祝禱】)
- 事件:一個穿著褪色祭袍的人站在村外,眼神還算清明。他盯著屋簷下掛著的異晶看了很久:「神的結晶……讓給我，我可以賜與你們一些神的恩賜。」
- 與他交換(異晶-100)→ 他教了村民一段不成調的低吟。說也奇怪,唱過之後,傷口沒那麼容易惡化了。(獲得【祝禱】:戰鬥中毒/流血的累積減半)
- 請他離開 → 他望著屋簷下的異晶,又看了你一眼,一步三回頭地走了。

**敘事碎片**(事件點 30% 機率;認知揭露第一階段——「曾有現代文明」的暗示):
1. 草叢裡有一小片又硬又輕的碎片,不是木頭也不是石頭。摸起來冰涼光滑,你說不出它是什麼。
2. 一截埋在土裡的細長金屬,筆直得不可思議——沒有任何鍛造的鎚痕。
3. 碎石堆下壓著一張脆化的紙片,上面印著整齊得詭異的小字。大部分已經模糊,只認得出一個詞:「……疏散……」
4. 半埋的木盒裡有一本泡爛的小冊子,字跡雋秀:「……他最近總是盯著院子裡那棵樹看,一句話也不說……」後面的頁面黏死了。
5. 一塊斷裂的平滑石板,表面刻著筆直的溝槽,溝槽裡殘留著暗色的、像是金屬的東西。
6. 你在樹幹上發現幾道抓痕。太高了——不管是什麼留下的,牠站起來比你高得多。
7. 風裡短暫飄來一段像是歌聲的聲音,又立刻消失了。方向不明。
8. 地上有一只小小的圓形玻璃片,磨得很精細,把景物放得很大。誰會做這種東西?又是為了看什麼?

**具名地標**:
- 鐵礦坑(未解放):山壁上一道人工開鑿的坑口,軌道的殘骸沒入黑暗。深處傳來沉重的呼吸聲——有什麼把這裡當成了巢穴。
- 鐵礦坑(解放後):礦坑已經安全了。村裡的人可以來這裡採鐵。
- 廢棄觀測台(未解放):山丘上立著一座奇怪的圓頂建築,頂端裂開一道縫,像一隻半闔的眼睛。門內有人影晃動——他似乎不歡迎訪客。
- 廢棄觀測台(解放後,輪播四段觀測紀錄):
  1. 「第 12 夜。倍率還是不夠我看得清楚,得再換一組鏡片才行。它表面的紋路,和去年畫下來的不一樣了。」
  2. 「第 31 夜。今晚很清楚。那東西肯定不是什麼隕石坑。隕石坑可不會動！」
  3. 「第 47 夜。我把畫拿給鎮上的人看,他們笑我。但沒有關係，我知道的，祂一直在看著我，我是祂在這片土地上的代行者，哈哈哈...」
  4. 紀錄到這裡就斷了。最後一頁只有一幅用力過猛的炭筆畫:一輪滿月,月面上纏繞著許多細長的、像根一樣的東西。
- 沼澤祭壇(未解放):水面中央露出一座石砌的平台,擺著燒過的痕跡與奇怪的刻紋。守著它的東西從水下浮了上來。
- 沼澤祭壇(解放後):祭壇安靜了下來。石縫裡的刻紋在光線下泛著微弱的暖意,像是餘燼。
- 煤礦坑(北嶺,未解放):半山腰裂開一道黑色的礦口,連風吹過都帶著煤灰味。坑道深處傳來規律的、像挖掘一樣的聲音——但這裡不該有任何人。
- 煤礦坑(解放後):煤礦安全了。烏黑的煤層在礦燈下泛著油亮的光——村裡的爐火,可以燒得更旺了。
- 靜默教堂(未解放):林子深處立著一座不該存在於這裡的尖頂建築。黑鐵的大門緊閉著。四周沒有聲音,連你自己的腳步聲都像被什麼吸走了。
- 靜默教堂(沒鑰匙,站上去):▍大門上懸著一把黑鐵巨鎖,鎖孔的形狀像一片葉子。推不開,也撬不動。
- 靜默教堂(解放後):教堂恢復了真正的寂靜。長椅的灰塵上只剩你的腳印。祭壇後的牆上,掛著一幅被刮花的畫——畫裡的東西你看不出來,也不想看出來。
