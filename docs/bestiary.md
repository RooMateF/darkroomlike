# 通用敵人圖鑑(草稿)

> 最後更新:2026-08-20
> 這份文件記錄「通用敵人」(非四大原始汙染/五位見證者這類劇情固定 Boss)的名冊草案,依威脅程度分三個梯隊。
> 每個敵人只給概念/招式方向,不寫死數值——具體強度依 design-notes.md § 2.9(敵方跑條速度反映招式強度)跟 resources.md 的資源/主線進度掛鉤。
> 遵守 worldbuilding.md 核心寫作原則:敵人描述不直接說破「這是被什麼汙染的」,只給可觀察的外觀/行為線索。

---

## 一、前期梯隊(冷兵器程度,分區外圍常見)

| 敵人 | 概念 | 招式方向 |
|---|---|---|
| 迷途者 | 衣衫襤褸的倖存者,神智尚算清醒,多半是被逼急了才攻擊,不是真正的威脅來源 | 單一低傷害近戰攻擊,速度慢 |
| 輕度發狂者 | 眼神渙散、動作不連貫的感染初期患者,攻擊毫無章法 | 攻擊速度不規律,偶爾出現「什麼都不做」的空轉行為 |
| 孳生失敗體(小型) | 瘟疫教派繁殖狂熱下的產物(worldbuilding.md § 7.2),外觀畸形、數量龐大、個體極弱 | 極快但極弱的單一攻擊,通常成群出現 |
| 變異犬 | 四肢比例不自然拉長的野獸,眼睛部位有輕微病變痕跡 | 撲咬攻擊,追擊速度快 |
| 廢土掠奪者 | 使用拼裝武器的人類幫派份子,單純為了搶劫資源而戰,不受汙染影響 | 冷兵器揮砍,可能繳械/搶奪玩家道具 |

## 二、中期梯隊(教派相關/初步異變,分區深處常見)

| 敵人 | 概念 | 招式方向 |
|---|---|---|
| 深淵教派狂信徒 | 完全臣服「解縛」教義的信徒,肢體動作帶有輕微不自然的扭曲感 | 近戰攻擊夾雜偶發的短暫視覺扭曲效果(呼應 § 7.1 現實扭曲症狀),可觸發「恐懼」異常 |
| 瘟疫教派接種者 | 主動接受低劑量汙染的信徒,皮膚有明顯病變但神智清醒、行動有紀律 | 近戰攻擊帶「中毒」異常疊加 |
| 魔女教派使役者 | 魔女教派信徒,身邊跟隨一兩隻行為異常的貓 | 信徒本體攻擊力普通,但貓會額外提供牽制/偷襲式攻擊 |
| 星空凝視者 | 星空教派信徒,持續望向天空、行為疏離,遭遇時常先愣住一段時間才反應 | 攻擊前搖長(呼應望遠鏡引誘的疏離感),但命中後附加「目盲/幻惑」異常 |
| 舊時代自律防衛機甲 | 戰前軍用防衛機具殘骸,AI 邏輯錯亂,對移動物體無差別開火 | 熱武器攻擊,固定路徑巡邏,不會主動追擊太遠,但攻擊頻率高、傷害穩定 |
| 孳生失敗體(中型) | 存活較久、體型明顯增大的孳生體,已不算「失敗品」等級 | 中等傷害的近戰攻擊,可能附加「中毒」 |

## 三、後期梯隊(重度異變,分區核心/深淵地圖常見)

| 敵人 | 概念 | 招式方向 |
|---|---|---|
| 深度汙染者 | 已完全喪失人形特徵的重度異變體,原本身分不可考 | 高傷害重擊,附加「流血」,行動槽跑得慢但單次很痛(呼應 § 2.9 慢條=痛的原則) |
| 深淵回聲 | 深淵教派狂信徒的極端型態,肢體扭曲幅度更劇烈 | 攻擊附加「恐懼」機率更高,偶發短距離的不自然位移(呼應柳樹的「分界」性質) |
| 孳生成體 | 完整成長、不再算失敗品的瘟疫產物,外觀已難以辨識原本可能是什麼 | 群體作戰,搭配小型孳生體一起出現,附加「中毒」與「腐蝕」(裝備劣化) |
| 荒蕪哨兵 | 舊時代自律防衛機甲的強化版本或多台協同版本 | 熱武器攻擊搭配範圍壓制,可能有短暫的「麻痺」附加效果(電力系统故障放電) |

## 四、野獸類補充(純自然 vs 變異,已定案需擴充)

威脅來源不該全部指向汙染——純自然的生存危險本身就該是重要的一環,才不會讓「野外」等於「汙染地圖」。分兩條線:

### 4.1 純自然野獸(未受汙染,純粹的生存威脅)

| 敵人 | 概念 | 招式方向 |
|---|---|---|
| 野豬 | 領域性強、易受驚擾就衝撞的大型野獸 | 蓄力衝撞,前搖長但傷害高,呼應「慢條=痛」的原則 |
| 禿鷲群 | 伺機而動的食腐鳥類,通常不主動攻擊健康目標,但會纏著已受傷的隊伍 | 低傷害多次騷擾攻擊,對「已流血/瀕死」目標命中率額外提升 |
| 毒蛇 | 生性隱蔽,遭遇多半是玩家不慎踩到 | 單次攻擊,附加「中毒」異常(非魔法/汙染來源的自然毒素) |
| 荒原巨熊 | 稀有但極危險的頂級掠食者,通常獨居 | 高傷害重擊,前期分區的實質「野生 Boss」等級威脅 |

### 4.2 變異野獸(受汙染程度不一)

| 敵人 | 概念 | 招式方向 |
|---|---|---|
| 變異犬(既有) | 四肢比例不自然拉長,眼睛部位有輕微病變痕跡 | 撲咬攻擊,追擊速度快 |
| 巨鼠群 | 數量異常龐大的鼠群,呼應瘟疫教派繁殖狂熱的邊緣產物(worldbuilding.md § 7.2),但比孳生失敗體更接近「正常生物過度繁殖」而非直接孕育 | 群體騷擾攻擊,附加輕微「中毒」,數量多但個體極弱 |
| 觸手化鹿群 | 軀體局部長出不屬於鹿的觸手狀組織,但行為模式仍保有鹿的溫馴天性,**不主動攻擊,受驚或被攻擊才反擊** | 平時可安全繞過,一旦交戰則爆發性高傷害反擊,是「該不該主動招惹」的風險判斷型敵人 |
| 巨型節肢生物 | 呼應瘟疫之主的蟑螂本源,外殼堅硬、行動敏捷,是介於「野獸」與「教派孳生物」之間的模糊個體 | 高頻率的多段快速攻擊(對應敵方跑條快=招式輕但煩人的設計) |
| 深水潛獵者 | 棲息於水域/沼澤地形的變異掠食者,平時潛伏不現身 | 突襲式攻擊(遭遇前無預警,呼應 § 1.3 氛圍警示文字系統的必要性),命中後附加「麻痺」 |

**設計意涵**:「觸手化鹿群」這類「不主動攻擊、可以選擇繞過」的敵人很值得多做幾隻——呼應世界觀「並非所有異變都等於邪惡/威脅」的細膩度,也給玩家在探索時多一層「要不要主動觸發戰鬥」的判斷空間,而不是所有敵人都必須硬碰硬。
