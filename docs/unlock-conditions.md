# 解鎖條件總表(武器/裝備/道具/建築/職業/被動)

> **用法**:與 `narrative-texts.md` 同一套流程——這是對照表,想調整哪個條件或數值,直接改這裡再跟我說「同步」。
> **通用原則(配方浮現)**:打造類項目不寫解鎖提示;配方要等玩家**「見過」所有材料**(曾經持有 >0)才會出現在列表,
> 湊不湊得齊數量只影響按鈕能不能按。建築另有各自的前置條件。

## 9. 進程與機制解鎖

| 內容 | 解鎖條件 |
|---|---|
| 整備出門(遠征) | 人口上限 ≥20(小木屋)**且蓋出田** |
| 前線補給基地($→S) | Lv1 / Lv3 探勘點打通後升格,可補水+領儲備 |
| 據點乾糧儲備 | 每個據點每趟遠征一次,隨機 5~15 份(受背包空間限制) |
| 據點休整 | 抵達自動回復缺損 HP 的 50%(每據點每趟一次);可再手動吃肉乾 +10 |
| 點燈 | 站在據點上、身上有燈油 ≥3 → 點亮(永久);曼哈頓 8 格內遭遇率 ×0.4 |
| 村莊威壓圈 | 中央地圖村莊周邊 6 格,遭遇率 ×0.3(常駐) |
| 鐵匠鋪(修鐵器) | 工匠鋪已建 + 鐵礦坑解放(自動升格) |
| 黑鐵鑰匙(教堂前置) | **打通離教堂最近的那座 Lv3 遺跡**;重要物品:不占格、不因死亡遺失 |
| 靜默教堂(Lv5) | 持有黑鐵鑰匙才能「深入調查」 |
| 相鄰地圖(北嶺/東郊廢墟/南原/西澤) | 走到中央地圖四邊的邊緣出口 → 按「前進」;野外一半機率遇中期梯隊敵人 |
| 觀測台紀錄輪播 | 觀測台解放後,每次再訪推進一段(共四段) |
| Lv2 被動回收 | 每打通一處 Lv2,村莊每週期 +木 2、石 1 |
| 礦坑解放獎勵 | 鐵 10+石 8;解鎖鐵礦工 |
| 觀測台解放獎勵 | 軍用刺刀 ×1 |
| 祭壇解放獎勵 | 火焰卷軸 ×2 |
| 教堂解放獎勵 | 異質短刃 ×1+卷軸 2+繃帶 3 |
