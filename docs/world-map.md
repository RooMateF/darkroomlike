# 世界地圖(完整對照)

> 地圖是**固定的**:以寫死的種子(20260821 系列)生成,任何時候重新生成都一模一樣,
> 不存在隨機刷新。死亡只是「檢查點之後的迷霧退回」,地形、點位永遠不變。
> 本筆記由遊戲程式即時抽出(2026-09,88×54 版+區域化地形);若日後改種子或尺寸,需重抽一次。
